# Casas Eco: portfólio de apresentação

Site de portfólio da **Casas Eco**, construtora e material de construção em Garopaba/SC.
Casas especiais em madeira e alvenaria, decks e pergolados.

## Estrutura

```
index.html      página única com todas as seções
style.css       estilos (cores, tipografia, layout, tema claro/escuro)
js/main.js      interações: menu, contadores, abas, vídeos, galeria, copiar número
img/            fotos e logo
video/          vídeos das obras (.mp4) e suas capas (.jpg)
```

## Seções

Abertura · Quem somos · Experiência · Como construímos (vídeos da cobertura) ·
Sistemas construtivos · Projetos · Portfólio de obras (galeria) ·
Construtora e material · Parceria CasaBio · Depoimentos · Contato

## Rodar localmente

O site é HTML/CSS/JS puro, sem build. Basta servir a pasta:

```sh
python3 -m http.server 8000
```

e abrir http://localhost:8000.

## Publicar

Pode ser publicado direto pelo GitHub Pages (Settings → Pages → branch `main`, pasta `/`).
