# Casas Eco: portfólio de apresentação

Site de portfólio da **Casas Eco**, construtora e material de construção em Garopaba/SC.
Casas especiais em madeira e alvenaria, decks e pergolados.

## Estrutura

```
index.html      página única com todas as seções
style.css       estilos: cores verde e branco, tipografia Archivo, layout
js/main.js      interações: menu, contadores, abas, corte da parede, vídeos,
                galeria, orçamento pelo WhatsApp, copiar número
fonts/          Archivo (servida do próprio projeto)
img/            fotos e logo
video/          vídeos das obras (.mp4, 720p) e suas capas (.jpg)
PRODUCT.md      quem é o cliente, o que o site precisa provar, compromissos da marca
DESIGN.md       o sistema visual: cores, tipos, componentes e regras
.claude/skills/ skills de design usadas no projeto (Impeccable e taste-skill)
```

## Seções

Abertura · Quem somos · Números · Showroom · Como construímos (vídeos da cobertura) ·
Sistemas construtivos (com o corte da parede) · Projetos · Portfólio de obras ·
Obra e material no mesmo lugar · Parceria CasaBio · Clientes ·
Comece seu orçamento (monta a mensagem e abre o WhatsApp) · Contato

## Rodar localmente

O site é HTML/CSS/JS puro, sem build. Basta servir a pasta:

```sh
python3 -m http.server 8000
```

e abrir http://localhost:8000.

## Publicar

Pode ser publicado direto pelo GitHub Pages (Settings → Pages → branch `main`, pasta `/`).
